stopped at every global proc without `READS_FROM`. They now judge the closed walk (`ReadsEngine::closed`, the one the generated subscriptions already used): engine bodies are
entered, a virtual call is the union of its overrides, a global proc is walked like any proc, and global state is classified (`sem/globals.rs`: written only while the world boots,
so it reads like a constant; a tracked var of a system; anything else is an input nothing publishes). **This is a change of measurement, not new debt.** The baselines were
