no proc, no new var and no CAPABILITIES entry and only sets var defaults (the tool's docstring has the rule). A family is the leaves'
direct parent. The sizes are a model (12.5 KB per /atom subtype from the memory report, 4 KB per /datum subtype), not a measurement;
the rule in `code/content/variants/README.md` still decides each family (no behaviour, no use of the type as an identity).
