# The include spec of deepquarry.dme (tools/build/gen_dme.py writes the manifest from it and the files on disk).
#
# Every .dm file under a `scan` root is included, in path order, unless a rule below places it. A rule exists only where the order
# changes what the compiled world does or whether it compiles; each says why. They were found by compiling the generated order against
# the old hand-kept order and comparing the worlds (bash tools/ci/dme_order_equiv.sh, dmb-equiv, game and test builds): a rule that
# is not needed is a bug, so drop it when its reason is gone (the generator refuses a rule that matches no file).
