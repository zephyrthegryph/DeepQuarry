# For initializer receiver observations

The C-style typed declaration branch in typed_statements.rs currently creates the
local slot but does not populate local_types like ordinary declarations. These
five independent compiler controls observe typed list Copy/Add, a source receiver
method, an untyped-dot contrast, and an ordinary typed-local control. No reference
acceptance or diagnostic is assumed; no production fix is made before capture.

The wrapper delegates to the existing loop_local_diagnostics launcher: explicit
DM/native/template SHA pins, serial 30-second compiler children, bounded overall
watchdog and 4GiB owned Job, source hash checks and unconditional reap. No DD.
Use --backend both and --output-root E:/dq-cache/dmb-for-initializer-receiver-diagnostics.
Exact diagnostics and SourceError class comparison are retained separately.
