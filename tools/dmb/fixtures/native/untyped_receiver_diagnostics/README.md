# Untyped receiver namespace controls

Compiler-only paired matrix for ordinary dot, explicit dynamic colon, source-known
names on unrelated owners, global-only names, native datum callbacks, native list
methods, unknown names, typed controls and self calls. These are minimal language
controls; the prohibited gameplay forms are intentional compiler fixtures.

The original sixteen controls retain authenticated BYOND expectations. The five
new verb-only dot/colon, mixed proc/verb, typed source verb and implicit self verb controls have no preselected outcome;
they require a new native capture before production verb coverage changes.
Receipt preserves exact source/compiler hashes,
acceptance, rejection classification, full diagnostic records and first messages.
No DreamDaemon starts. Existing owned Job caps aggregate compiler memory at 4GiB,
children run serially with 30s watchdogs and total matrix 90s, with unconditional reap.
All outputs default to E:/dq-cache/dmb-untyped-receiver-diagnostics.

Run `python run.py --native EXE --native-sha256 SHA --template DMB
--template-sha256 SHA --dm EXE --dm-sha256 SHA` with explicitly pinned files.
Exit succeeds only for completed acceptance and source-rejection-class agreement.
Exact diagnostic agreement remains reported separately, without normalization.
Existing captured list Copy and unknown untyped cases are independent native
controls in fixtures/phase1/native_intrinsic_field_types.

`--backend byond-only` captures authenticated reference observations without a
native compiler or template; only DM and its SHA flags are required. Default
`both` still requires all pins. `byond_observations.json` freezes the captured
reference outcomes; runner rejects changes without claiming paired parity.
