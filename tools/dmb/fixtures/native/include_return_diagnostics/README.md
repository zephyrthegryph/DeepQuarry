# Include-return diagnostic discovery

Compile-only paired cases cover terminal, omitted define/conditional directives,
nested/repeated includes, a nonterminal parent token, continued include spelling,
and missing final newlines. No reference locations or messages are guessed.

`run.py --native EXE --native-sha256 SHA --template BIN --template-sha256 SHA
--dm "D:/Program Files (x86)/BYOND516/bin/dm.exe" --dm-sha256
8cac7e8bd48219f8a7fb622535a1ce1a914d0a9a3e909bc9ceb84b3074709dc0`

Use one shell line. `--backend byond-only` requires only the DM pin. Evidence is
preserved under a unique E:/dq-cache/dmb-include-return-diagnostics directory.
All source bytes and compiler/template inputs are hashed before and after.
Children use the existing suspended owned Job launcher (4GiB), serial 30 second
watchdogs and a 300 second overall deadline, with unconditional owned reap.
No DreamDaemon is launched. Paired success requires exact ordered diagnostic
agreement and native source-error status 2 for reference source rejections.
Discovery evidence is complete capture, not a runtime or full compiler gate.
