# dm-preprocess

Ordered DME and DM include expansion with explicit source dependencies and output-line origins. `SourceProvider` abstracts source reads so the incremental compiler can route them through tracked file inputs. Include occurrences are retained even when the same file is visited twice, because macro state and declaration override order can differ.

The initial implementation supports object and function macros, named variadic macros, `##` token paste, `#X` argument stringification, `#define`, `#undef`, `#include`, `#ifdef`, `#ifndef`, integer `#if`/`#elif` expressions, `#else`/`#endif`, continued physical lines, multiline block strings, and include-cycle diagnostics. Conditional expressions support `defined`, parentheses, integer arithmetic, comparisons, shifts, and logical and bitwise operations. The output map records physical source lines, including multiline strings. Macro references inside string interpolation are expanded while literal text remains untouched. Other BYOND-specific preprocessing details still need fixtures before they can be claimed as supported. Diagnostics have typed categories; callers should reject output when errors are present.
